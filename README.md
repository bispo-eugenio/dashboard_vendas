# Primeiro Projeto com Streamlit

Esse dashboard visualiza dados fictícios de vendas, permitindo filtragem e análise dinâmica criados pelo altair e streamlit.

## Objetivo
Aprender as funcionalidades do [Streamlit](https://streamlit.io/) e [Altair](https://altair-viz.github.io/) para futuros projetos.

## Como Executar:

```bash
git clone https://github.com/bispo-eugenio/dashboard_vendas.git
cd dashboard_vendas
```
### Crie um ambiente virtual (Opcional/Recomendação):
```bash
python -m venv venv
source venv/bin/activate #Linux/Mac
venv\Scripts\activate #Windows
```
### Instale as dependências do requirements.txt:
```bash
pip install -r requirements.txt
```
### Execute o app:
```bash
streamlit run main.py
```
